# <p align="center"> Open Source Events to attend in 2027 :sparkles: </p>

This is a collection of Open Source events or conferences to look out for in 2026.

How can you make the best out of these events or conferences?

- Checkout for the Call for Proposals and submit a talk or workshop.
- Look for opportunities to contribute to the conference through volunteering. Some examples are;
  - Watching out for and reporting typos found on the conference website
  - Volunteering on site or online before or during the conference
  - Offering to coach new speakers before the conference
  - Help market the conference
- Sponsor an event.
- Checkout for grants or financial aid offered by the conference.

If you are interested in contributing to this project, kindly read the [contribution guideline](https://github.com/Everything-Open-Source/open-source-events/blob/main/contributing.md).

<h2> 📆 Subscribe to the Calendar </h2>

Stay updated with all these open source events by subscribing to our calendar:

**ICS Calendar**: [https://jonamarkin.github.io/ose-calendar/events.ics](https://jonamarkin.github.io/ose-calendar/events.ics)

### How to Subscribe:

- **📌 Google Calendar**:

  1. Click the "+" next to "Other calendars"
  2. Select "From URL"
  3. Paste the calendar URL and click "Add calendar"

- **📌 Apple Calendar**:

  1. Go to File > New Calendar Subscription
  2. Paste the calendar URL or use: `webcal://jonamarkin.github.io/ose-calendar/events.ics`

- **📌 Outlook**:
  1. Go to Calendar view > Add Calendar > Subscribe from web
  2. Paste the calendar URL

The calendar is automatically updated daily, ensuring you always have the latest event information.
